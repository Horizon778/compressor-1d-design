### Web APP

用浏览器打开 `web/app.html`。左侧改参数，右侧实时出结果，无需安装任何东西。

页面结构（按论文截面顺序）：

```
① 吸气室 0-0   ② 叶轮进口 1-1   ③ 叶轮出口 2-2
④ 无叶段 3-3   ⑤ 叶片扩压器 4-4  ⑥ 蜗壳 5-5
⑦ 子午流道     ⑧ 校核判据       ⑨ CFturbo 填表清单
```

每条参数旁标注对应的论文公式号（如 `(2-32)`），方便回溯。

### Python 包

```bash
cd <repo-root>

# 正向设计：从工况算几何 + 判据
python -m design_1d.run design --case y7v2

# 逆向体检：把已建好的几何反算成无量纲量
python -m design_1d.run audit  --case y7v2

# 画子午线（含内切圆、面积、曲率）
python -m design_1d.run meridian --case y7v2 --out mer.png
```

算例参数写在 `design_1d/cases/y7v2.py`，改那里的 `DESIGN`（设计工况）和 `MACHINE`（实际几何 + CFD 结果）。

## 论文公式的三处错误（本实现已修正）

照抄原文会得到错误结果，这三处必须改：

**1. 式(2-45) 音速公式量纲不对**

原文：`Mc3 = c3 / sqrt(20.1·T3)`
实际：`a = sqrt(k·R·T) = 20.05·sqrt(T)`（k=1.4, R=287.1）

按原文实现会把扩压器进口马赫算成 1.08 的假超音速。

**2. 式(2-27) 滑移系数不是 Wiesner 原式**

原文：`μ = 1 − 0.7·sinβ2A / z^0.7`
Wiesner(1967)：`μ = 1 − sqrt(cosβ2A) / z^0.7`

z=18、β2A=38° 时两者给 0.943 vs 0.882，差 7%，直接决定 c2u 是否自洽（滑移偏差从 8.8% 降到 1.8%）。

**3. 式(2-62) 在等宽扩压器上不产生扩压**

`b4 = b3` 时 sinβ 比会给出 `c4 ≈ c3`，与"扩压器要升压"矛盾。
改用连续性：`c4 = c3·r3/r4`。

另外式(2-61) 的当量扩张角：等宽扩压器的 θ 由叶片数/半径比唯一决定，不是自由变量。
硬套 θ=9° 会算出 40 片、稠度 2.7（超标）。本实现按稠度 1.45 反算叶片数。

## 一处方法改进：子午流道

论文用五点四次贝塞尔 + 端点曲率反解中间控制点（式 2-76~2-86）。该方法的固有缺陷：

端点曲率取 0 时，解出的中间控制点 P2 必然落在**进口半径**上
（P2r 只依赖 P3r/P4r 和端点切线，与切向量长度无关）。
结果前三个控制点 r 相同，曲线前段几乎不动、后段猛涨，
通道中段不收缩，**流通面积先鼓后收**（本算例 65→78→52 cm²）。

论文表 2-3 也呈现这个特征：轮毂 H2 在 89% 轴向位置时半径只走了 6%。

本实现提供两种构造：

- `web/app.html`：保留论文的贝塞尔（可调 θ0/θ4/λ/Δz），并显示内切圆半径单调性作为判据
- `design_1d/bezier.py`：另提供 `build_by_area()` —— 先给面积分布 `A(s)`，由
  `r_h(s) = sqrt(r_s(s)² − A(s)/π)` 反求 hub，面积精确单调

实际在 CFturbo 里建模时，只需锁三件事：进口两个半径、出口 `r2` 与 `Hub-Shroud 的 z 差 = b2`、
右键 `Start angle=0° / End angle=90°`。中间控制点让软件自己走即可，不必照抄论文坐标。

## 校核判据

14 条，分三类：

| 类别 | 判据 | 推荐范围 | 依据 |
|---|---|---|---|
| 叶轮 | 叶尖进口相对马赫 Mw1 | ≤ 0.90 | 亚音速设计上限 |
| | 相对速度减速比 w2/w1 | ≥ 0.72 | de Haller |
| | 负荷系数 ψ = Δh/u2² | 0.50~0.68 | Aungier |
| | 出口流量系数 φ2 = c2r/u2 | 0.20~0.35 | Aungier |
| | 落后角 β2A−β2 | 2~12° | Cumpsty |
| | 滑移偏差 (Wiesner vs 一维) | ≤ 5% | — |
| | 叶顶间隙比 t/b2 | ≤ 5% | 半开式经验 |
| 扩压器 | 无叶段长度比 k3 = r3/r2 | 1.08~1.20 | 论文 |
| | 半径比 ky = r4/r3 | 1.20~1.40 | 论文 |
| | 进口马赫 M3 | ≤ 0.85 | — |
| | 叶片稠度 σ | 1.0~1.8 | Aungier |
| | 叶片数公约数 gcd(zy, z) | ≤ 2 | 避免声学共振 |
| 蜗壳 | 出口马赫 M5 | ≤ 0.15 | — |
| | 出口/进口面积比 | 1.2~3.5 | 经验 |

`k3 ≈ 1.0` 是最容易忽略又最要命的一条：叶片扩压器直接贴在叶轮出口，射流尾迹没机会掺混，
前缘必然冲击。

## 叶轮损失模型（Web APP 内）

η 不再是纯输入，而是由 5 项损失算出：

| 损失项 | 估算式 | 典型占比 |
|---|---|---|
| 摩擦 | `4·Cf·(L/Dh)·W̄²/2`，Cf=0.005 | ~1% |
| 冲击 | `0.5·(w1·sin i)²/2` | ~0%（设计点） |
| 叶顶间隙 | `0.6·(t/b2)·c2u²/2` | ~1.2% |
| 轮盘摩擦 | `0.012·u2²` | ~2% |
| 回流 | `0.015·u2²` | ~2.6% |

**系数不确定度 ±30%**，用途是判断"哪项占大头"，不是精确预测。
输出叶轮多变效率 `ηp = 1 − Δh_loss/Δh_euler`，可与输入的整机 `ηtt` 对照。

## 已知限制

1. **一维模型不含实验标定**。所有经验系数（压头系数、σ、kwid）取值来自文献范围，
   不同机型需要重新校核。
2. **损失模型是系数式**，不区分具体流动机理（如二次流、尾迹掺混的细节），
   只给量级和相对占比。
3. **子午线判据只查单调性**，不保证气动最优。真实最优型线需要三维反问题或优化。
4. **未做变工况**。当前只算设计点，特性线（变转速/变流量）尚未实现。
5. **角度定义**：本工具与 CFturbo 一致，β 从**切向**测量（β=90° 为径向叶片），
   直接照抄即可，不要做 90−β 换算。
